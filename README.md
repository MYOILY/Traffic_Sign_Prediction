# Traffic Sign Classification (Deep Learning)
Develop a computer vision model to accurately classify traffic signs to support intelligent transportation systems and autonomous driving applications.

### Dataset
Public traffic sign dataset (e.g., GTSRB)

X classes

X,XXX labeled images

Varying lighting and angle conditions

### Data Processing

Resized and normalized image inputs

Applied data augmentation (rotation, scaling, brightness adjustment)

Split dataset into training, validation, and testing sets

### Model Development
Implemented Convolutional Neural Network (CNN) using TensorFlow / PyTorch

Tuned hyperparameters (learning rate, batch size, epochs)

Applied dropout and regularization to prevent overfitting

### Results
Achieved 85% classification accuracy on test dataset

Confusion matrix analysis to identify misclassified categories

Improved baseline accuracy by 30% through augmentation

### Business / Real-world Implication
Supports development of Advanced Driver Assistance Systems (ADAS)

Enhances road safety through automated sign recognition
